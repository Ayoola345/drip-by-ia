# 👕 Drip by I&A

A vintage and thrift fashion website built with HTML, CSS, and JavaScript.

Drip by I&A is a fashion website designed to showcase unique vintage, thrift, and streetwear pieces while giving customers an easy way to explore products and place orders through WhatsApp.

## ✨ Features

- Responsive fashion website
- Multi-page navigation
- Product search
- Category filtering
- Shopping cart functionality
- Cart total calculation
- Remove items from cart
- WhatsApp product ordering
- WhatsApp cart checkout
- Dark mode
- Contact form
- Responsive design for mobile and desktop
- Scroll-to-top functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Formspree
- Git & GitHub
- GitHub Pages

## 📄 Pages

- **Home** — Introduction and featured products
- **Shop** — Product collection, search, filters, and shopping cart
- **About** — Brand story and values
- **Contact** — Contact information and message form
